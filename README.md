🐾 PetCareApp – Flutter Application
📌 Project Overview

PetCareApp is a comprehensive Flutter-based mobile application designed to manage pet care services.
It supports three types of users – Shelter Admin, Pet Owners, and Veterinarians – providing role-based access and features to streamline pet management and care services.

The app allows pet adoption, medical tracking, and appointment management with a clean and interactive UI.

🧠 About the Project

PetCareApp aims to make pet care and shelter management efficient, transparent, and user-friendly.
Each user type has dedicated functionalities:

👤 Shelter Admin

Add, update, and remove pets in the shelter

Manage adoption requests

Monitor shelter activities

🐶 Pet Owner

Create and manage pet profiles

Submit adoption requests

Book veterinary appointments

🩺 Veterinarian

Access pet medical records

Approve or manage appointments

Track pet health history
